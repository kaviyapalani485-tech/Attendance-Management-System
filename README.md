Attendance Management System

Project Description

Attendance Management System is a Java-based application developed to manage student attendance efficiently.

The system helps users record, view, and manage student attendance details.

Features

- Add Attendance
- View Attendance
- Search Attendance
- Update Attendance
- Delete Attendance
- Manage Student Attendance
- Store Attendance Records

Technologies Used

- Java
- JDBC
- MySQL
- Eclipse IDE

Architecture

The project follows a Layered Architecture:

- Model
- Repository
- Service
- Controller
- Database

Database

MySQL is used to store student attendance information.

Attendance Table

Field| Description
ID| Attendance ID
Student Name| Name of the Student
Date| Attendance Date
Status| Present / Absent

How to Run

1. Install Java JDK.
2. Install MySQL.
3. Create the required database and attendance table.
4. Configure the database username and password.
5. Open the project in Eclipse IDE.
6. Add MySQL Connector/J.
7. Run the main Java file.

Project Outcome

The system provides a simple and efficient way to manage student attendance records using Java, JDBC, and MySQL.

Future Enhancements
